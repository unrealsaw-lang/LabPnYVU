# Языковая школа

## Задача

Языковая школа организует курсы иностранных языков разных уровней. Каждый курс имеет язык, уровень, преподавателя, расписание и максимальное количество студентов. Один преподаватель может вести несколько курсов. Студент может посещать несколько курсов. Необходимо контролировать заполненность групп и соответствие уровня студента уровню курса.

## Возможности программы:

- Создание курсов с указанием языка, уровня, преподавателя, расписания и максимального количества студентов
- Добавление студентов на курсы с проверкой заполненности группы
- Добавление преподавателей к курсам
- Отчисление студентов с курсов
- Удаление преподавателей с курсов
- Удаление курсов
- Просмотр информации о курсах, студентах и преподавателях
- Демонстрация работы перегруженных операторов

## Классы:

### Course
Атрибуты: язык, уровень, расписание, максимальное количество студентов, список студентов, список преподавателей.

Методы: добавление и удаление студентов и преподавателей, поиск по имени, геттеры и сеттеры, вывод информации.

Ограничение: количество студентов не может превышать максимальное значение.

### Student
Атрибуты: имя, список курсов, на которые записан.

Методы: запись на курс, отчисление с курса, геттеры и сеттеры, вывод информации.

Ограничение: не более 10 курсов на одного студента.

### Professor
Атрибуты: имя, список курсов, которые ведёт.

Методы: добавление и удаление курса, геттеры и сеттеры, вывод информации.

Ограничение: не более 10 курсов на одного преподавателя.

## Перегруженные операторы

### Операторы сравнения
Для класса Course оператор `==` сравнивает курсы по языку и уровню, а операторы `<` и `>` — по количеству записанных студентов.

Для класса Student оператор `==` сравнивает студентов по имени, а операторы `<` и `>` — по количеству курсов, на которые студент записан.

Для класса Professor оператор `==` сравнивает преподавателей по имени, а операторы `<` и `>` — по количеству курсов, которые они ведут.

Операторы `!=`, `<=`, `>=` реализованы через уже определённые `==` и `<`.

### Операторы потокового ввода-вывода
operator<< - вывод информации об объекте.

operator>> - ввод данных объекта.

### Операторы управления коллекцией
operator+= - добавление студента на курс или курса студенту или преподавателю.

operator-= - удаление студента с курса или курса у студента или преподавателя.

### Дружественные функции
Операторы << и >>, а также операторы сравнения объявлены друзьями классов и имеют доступ к закрытым полям.

## Обработка невозможных операций

- Добавление nullptr в коллекцию
- Превышение максимального количества студентов на курсе
- Превышение максимального количества курсов у студента или преподавателя
- Попытка добавить уже существующий элемент
- Некорректный ввод: пустые строки, отрицательная вместимость
